# 高年级学生专项特长系统

## 系统概述

为高年级（大三、大四）学生设计的特殊能力机制，模拟"非核心球员得不到大量培养资源"的现实情况。这些球员会在特定领域（篮板或防守）有突出表现，但综合能力值较低。

## 核心机制

### 1. 专项类型

#### 篮板专家 (REBOUNDING)
- **图标**: 🏀
- **主要强化**: 篮板 (+25%)
- **次要强化**: 力量、盖帽 (+15%)
- **削弱属性**: 投篮 (-20%)、三分 (-25%)、传球 (-15%)、控球 (-15%)

#### 防守专家 (DEFENSE)
- **图标**: 🛡️
- **主要强化**: 防守 (+25%)
- **次要强化**: 抢断、盖帽 (+15%)
- **削弱属性**: 投篮 (-20%)、三分 (-25%)、得分 (-15%)、传球 (-10%)

### 2. 生成概率

| 年级 | 成为专项球员概率 | 说明 |
|------|-----------------|------|
| 大一 | 0% | 新生不触发 |
| 大二 | 0% | 二年级不触发 |
| 大三 | 40% | 较高概率成为专项球员 |
| 大四 | 60% | 高概率成为专项球员 |

### 3. 能力值调整

#### 综合能力值惩罚
- 大三专项球员: -5
- 大四专项球员: -8

#### 潜力值调整
- 大三专项球员: -5
- 大四专项球员: -10

### 4. 招募要求（降低）

专项球员的招募要求显著低于普通球员：
- 最低奖学金: 30%
- 期望奖学金: 50%
- 最高奖学金: 70%
- 期望出场时间: 15分钟
- 招募难度: 简单
- 接受率加成: +15%

## 游戏平衡性设计

### 1. 优势
- **特定场景强力**: 在篮板或防守方面有突出表现
- **招募成本低**: 奖学金要求低，容易签约
- **即战力**: 虽然综合能力低，但特定属性高，可以即插即用

### 2. 劣势
- **综合能力低**: 整体能力值明显低于同年级普通球员
- **发展潜力有限**: 潜力值被削减，成长空间有限
- **功能单一**: 只能在特定领域发挥作用
- **非核心定位**: 得不到大量培养资源

### 3. 使用策略
- **角色球员**: 作为轮换阵容的特定功能球员
- **防守 specialist**: 需要防守时使用
- **篮板手**: 需要保护篮板时使用
- **低成本补充**: 预算有限时的性价比选择

## 代码使用示例

```javascript
// 初始化系统
const specialistSystem = new SeniorSpecialistSystem();

// 处理高年级球员
const seniorPlayer = {
    name: '张三',
    year: 3,
    position: 'PF',
    rating: 65,
    potential: 75,
    attributes: { ... }
};

const processedPlayer = specialistSystem.processSeniorPlayer(seniorPlayer);

// 检查结果
if (processedPlayer.specialistInfo) {
    console.log(`${processedPlayer.name} 是 ${processedPlayer.specialistInfo.name}`);
    console.log(`强项: ${processedPlayer.specialistInfo.primaryAttribute}`);
    console.log(`综合能力值: ${processedPlayer.rating} (降低了 ${65 - processedPlayer.rating})`);
}
```

## 注意事项

1. **平衡性**: 专项球员的综合能力值必须低于同年级普通球员
2. **可识别性**: UI上要清晰标识专项球员
3. **招募策略**: 专项球员是低成本的功能性选择，不是主力培养对象
4. **成长限制**: 专项球员的潜力值被削减，成长空间有限
